📬 Hauspost Scanner – Einrichtung

Damit die App Dateien in deinen Google Drive hochladen kann, brauchst du eine Google OAuth Client-ID. Das klingt kompliziert, ist aber in 5 Minuten erledigt – und kostenlos.

Schritt 1 – Google Cloud Projekt erstellen

1. Öffne console.cloud.google.com
2. Klicke oben auf "Projekt auswählen" → "Neues Projekt"
3. Name z.B. Hauspost Scanner → "Erstellen"

Schritt 2 – Google Drive API aktivieren

1. Gehe zu "APIs & Dienste" → "Bibliothek"
2. Suche nach Google Drive API
3. Klicke darauf → "Aktivieren"

Schritt 3 – OAuth Zustimmungsbildschirm konfigurieren

1. Gehe zu "APIs & Dienste" → "OAuth-Zustimmungsbildschirm"
2. Wähle "Extern" → "Erstellen"
3. App-Name: Hauspost Scanner, Support-E-Mail: deine Gmail
4. Klicke durch bis "Speichern und fortfahren"
5. Unter "Testnutzer": füge deine eigene Gmail-Adresse hinzu

Schritt 4 – OAuth Client-ID erstellen

1. Gehe zu "APIs & Dienste" → "Anmeldedaten"
2. Klicke "Anmeldedaten erstellen" → "OAuth-Client-ID"
3. Anwendungstyp: Webanwendung
4. Name: Hauspost Scanner Web
5. Unter "Autorisierte JavaScript-Quellen" add:
  → https://DEIN-USERNAME.github.io (für GitHub Pages)
  → http://localhost:8000 (zum lokalen Testen)
6. Klicke "Erstellen"
7. Kopiere die Client-ID (endet auf .apps.googleusercontent.com)

Schritt 5 – App auf GitHub Pages hosten

1. Erstelle ein kostenloses Konto auf github.com
2. Erstelle ein neues Repository namens hauspost-scanner
3. Lade alle App-Dateien hoch (index.html, style.css, app.js, ...)
4. Gehe zu Settings → Pages → Source: main branch
5. Deine App ist dann erreichbar unter:
  https://DEIN-USERNAME.github.io/hauspost-scanner
6. Diese URL auf deinem Handy in Chrome öffnen → "Zum Startbildschirm hinzufügen"

Schritt 6 – Client-ID in der App eintragen

1. Öffne die App → du siehst den Einrichtungsbildschirm
2. Füge deine Client-ID ein → "Speichern & starten"
3. Fertig! Die Client-ID wird lokal im Browser gespeichert.
Tipp: Der "Hauspost"-Ordner wird automatisch in deinem Google Drive erstellt, wenn du zum ersten Mal ein PDF hochlädst. Du musst nichts manuell anlegen.

Lokales Testen (optional)

Falls du Python installiert hast, kannst du die App lokal testen:
python serve.py
Dann im Browser öffnen: http://localhost:8000
